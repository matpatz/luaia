# Contributing

## Style Guide

### Variables

Use PascalCase for all variable names.

```lua
-- Good
local MyVariable = 1
local PlayerHealth = 100
local MaxRetries = 3
local MaxPlayers = 16

-- Bad
local my_variable = 1
local playerHealth = 100
local max_retries = 3
local MAX_PLAYERS = 16
```

### Functions

Use PascalCase for function names.

```lua
-- Good
local function CalculateDamage()
local function GetPlayer()

-- Bad
local function calculate_damage()
local function get_player()
```
